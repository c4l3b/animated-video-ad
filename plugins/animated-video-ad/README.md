# animated-video-ad

Turns an app or product into a short promo video. Claude animates the product's real screenshots
and numbers as HTML shots, records each to an MP4 clip at the right shape for the platform, and
writes a script doc with the cut order, trims, speeds and voice-over lines. Optional music (a
generated bed, your own track, or ElevenLabs Music) and an optional ElevenLabs voice-over, plus a
rough-cut preview. Needs Chrome, Node with Playwright, ffmpeg and Python 3 with numpy. See the
repository README for details.

Install in Claude Code:

```
/plugin install animated-video-ad --marketplace c4l3b/animated-video-ad
```
